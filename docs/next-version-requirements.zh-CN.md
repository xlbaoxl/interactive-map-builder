# 两张地图优化实施记录

更新日期：2026-07-25

状态：已实现并纳入本次 `main` 更新

适用版本：`0.2.0` 后续体验优化（不修改包版本）

## 共同规则

### 地名保留官方原文

- 地理专名沿用数据源或官方资料中的原文与拼写。
- `Lower Manhattan`、`Financial District`、`Civic Center`、`Downtown Brooklyn`
  等名称不汉化。
- “地块与用地”“搜索”“图层”等通用界面文案仍可本地化。
- README、示例配置、演示站和截图说明使用同一规则。

### 悬浮提示长文本不越界

定位结果为 Leaflet 默认 `.leaflet-tooltip { white-space: nowrap; }` 抵消了内部字段
已有的断行能力。通用样式现已：

- 覆盖单行限制并设置视口相关最大宽度；
- 允许中文、英文、长地址和无空格连续字符串安全断行；
- 允许标签和值两列收缩，不通过截断数据或缩小字体掩盖问题；
- 通过真实 hover 浏览器测试比较提示内容与外框边界。

### 控件必须产生可观察结果

- 控件不能只改变按钮颜色而不显示内容或改变结果。
- 浮层不得被父级滚动区或命令栏裁剪。
- 键盘焦点、展开状态、外部点击和 `Escape` 关闭行为必须明确。

## `map-list` 地块地图

### 数值范围筛选

- “建成年份”“楼层数”“已建容积率”浮层挂载到页面顶层并按触发按钮定位。
- 浮层保持在视口内，多个浮层互斥，支持外部点击和 `Escape` 关闭。
- 修改范围后同步更新地图、列表、KPI、活动筛选数量和按钮摘要。

### 列表排序与卡片

- “列表排序”放在左侧列表标题区，明确只控制列表顺序。
- 卡片完整显示配置的主要属性，不再只显示独立“排序值”。
- 当前排序字段在其正常位置高亮；按地址排序时高亮卡片标题。
- 卡片使用与图例一致的浅色背景和色边表达类别，不重复类别文字。
- 卡片只保留物业地址作为标题；隐藏程序内部 `lot-…` ID，BBL 仅在详情中显示。
- 字段名称使用“地址”，避免把地址误解为官方唯一地块名称。

## `multilayer` 多业务图层地图

### 示例内容

- 地铁站：16 个由出入口聚合得到的站点；
- 自行车线路：36 条按街道和设施等级整理的线路；
- 邻里分区：4 个相邻的官方 Neighborhood Tabulation Areas。

地图标题使用 `Downtown Brooklyn`，邻里、车站和街道名称保留官方英文原名。

### 图层颜色与搜索

- 自行车线路按设施等级在图面和图例中使用同一套可辨识颜色。
- 搜索不再跨不同实体类型混合匹配。
- 左侧使用“地铁站 / 自行车线路 / 邻里分区”业务名称切换搜索图层。
- 点只按车站字段搜索，线只按线路字段搜索，面只按邻里字段搜索。
- 切换图层时同步更新字段名称、占位提示、结果类别与数量；其他图层继续作为空间
  上下文显示。

## Skill 蒸馏

已将以下经验写入 `SKILL.md`、`references/design-guidelines.md` 和
`references/map-spec.md`：

- 区分稳定唯一的 `id_field` 与面向用户的 `label_field`；
- 保留官方地名，不翻译地理专名；
- 用户真实几何不得为了视觉美观而筛除或重构；
- 图层使用业务名称并按业务图层搜索；
- 卡片属性、排序高亮、技术 ID、图例同色和无障碍名称的展示原则；
- 数值筛选浮层、键盘与焦点行为；
- 分类线颜色必须在图面可辨识并匹配图例；
- 所有控件必须产生可观察结果。

仓库演示数据如何选材不属于用户数据处理规则，因此未写入“示例数据应避免狭长碎片
地块”之类的 Skill 约束。
